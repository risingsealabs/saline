supercop.js 2.0.1
----------------
The package describes itself as orlp/ed25519 compiled with Emscripten. Its
published index.js and lib.js match the shipped Tendermint bundle modules
118 and 119 (after line-ending normalization and Browserify wrapping).
The wrapper's ISC declaration is recorded in javascript-bundles.txt.
The following notices cover the independently licensed underlying code.

Upstream package revision:
https://github.com/1p6/supercop.js/tree/e292dafa1e1a7127b259b806a1a5b966e4ae2f6f
Its build.js invokes emcc over supercop.c and vendor/src/*.c; the vendor script
clones https://github.com/orlp/ed25519.git. Neither the vendor revision nor the
compiler version was pinned. The notices below use contemporary upstream
sources; they do not claim to reconstruct that missing build information.
The C implementation is distributed in Emscripten-generated JavaScript form,
with a JavaScript wrapper added by supercop.js; it is not the original C tree.

hash.js, not an unmodified copy of the entire Closure Library.
